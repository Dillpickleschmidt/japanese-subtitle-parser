### Pattern Implemented: とか～とか (things like... and...)

**JLPT Level**: N4
**Category**: Construction
**Priority**: 2

**Pattern**: Listing particle used for providing non-exhaustive examples. とか follows verbs, adjectives, or nouns to indicate "things like" or "among other things". Can appear multiple times in a sentence to list several examples, with the last item optionally omitting とか. Implies there are other items in the category beyond those explicitly stated.

**Structures tested**: 4 tests covering all structure variants

### Technical Notes

**Listing Particles in Japanese**:
This pattern is part of the listing particle family:
- とか: Non-exhaustive listing (verbs, adjectives, nouns) - casual
- や: Non-exhaustive listing (nouns only) - more formal
- と: Exhaustive listing (complete list)
- Difference: とか/や imply "among other things", と means "only these items"

**Multiple Pattern Matches**:
Unlike most patterns that match once per sentence, とか～とか creates multiple matches when とか appears multiple times. This is intentional - each instance of とか is a separate grammatical unit worth highlighting.

### Pattern Implemented: とかんがえられている (it is thought/considered that)

**JLPT Level**: N4
**Category**: Construction
**Priority**: 1

**Pattern**: Expresses that something is commonly thought or considered to be true by people in general. This is a passive quotative construction combining the quotative particle と with passive forms of either 考える (to think/consider) or 思う (to think). Translates as "it is thought that..." or "it is considered that...".

**Pattern name note**: The pattern is named とかんがえられている but it matches BOTH:
- とかんがえられている (と考えられている) - "it is thought/considered that"
- とおもわれている (と思われている) - "it is thought that"

Both variants use the same grammatical structure (quotative と + passive verb + ている) and convey essentially the same meaning - expressing common/public opinion rather than personal opinion.

**Structures tested**: 4 tests covering both verb variants
1. Phrase + とかんがえられている (standard): 志村けんだとかんがえられている (Shimura Ken is considered to be...)
2. Phrase + とおもわれている (standard): トンネルだとおもわれている (thought to be a tunnel)
3. Phrase + とかんがえられています (polite): 動物だとかんがえられています (is considered to be an animal)
4. Phrase + とおもわれています (polite): 遺跡だとおもわれています (is thought to be ruins)

### Technical Notes

**Passive Quotative Construction Pattern**:
This pattern continues the passive quotative series:
- Content + と (quotation) + Verb[passive] + ている
- The と marks what precedes it as quoted or considered content
- Passive form indicates the content is something "thought by people in general"
- ている expresses ongoing state (it's commonly/currently thought)

**Verb Conjugation for Passive**:
Understanding how passive forms work:
- 一段 verbs: Remove る, add られる (e.g., 考える → 考えられる)
- 五段 verbs: Change to 未然形, add れる (e.g., 思う → 思われる)
- する verb: Special form さ + れる (e.g., する → される)
- 言う verb: 言わ + れる (e.g., 言う → 言われる)

**Comparison of Passive Quotative Verbs**:
- 考えられている: "is considered/thought" (more formal, analytical)
- 思われている: "is thought/believed" (more general, emotional)
- 言われている: "is said" (hearsay, what people say)
- されている: "is done/regarded as" (classification, status)
