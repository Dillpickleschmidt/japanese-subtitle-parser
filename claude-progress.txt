### Pattern Implemented: ば (conditional "if")

**JLPT Level**: N4
**Category**: Construction
**Priority**: 2

**Pattern**: The ば conditional form is one of the most fundamental conditional structures in Japanese. It expresses hypothetical situations and possibilities using the 仮定形 (hypothetical form) conjugation + ば particle.

**Structures tested**: 13 tests covering all major variants
1. る1-Verb (ichidan): 見る → 見れば (if you watch)
2. る5-Verb (godan): 座る → 座れば (if you sit)
3. う-Verb: 歌う → 歌えば (if you sing)
4. く-Verb: 歩く → 歩けば (if you walk)
5. す-Verb: 話す → 話せば (if you talk)
6. する exception: する → すれば (if you do)
7. くる exception: くる → くれば (if you come)
8. い-Adjective: 痛い → 痛ければ (if it hurts)
9. な-Adjective: 嫌い + ならば (if you dislike)
10. Noun: バイク + ならば (if it's a bike)
11. Verb negative: 食べたくなければ (if you don't want to eat)
12. い-Adjective negative: 辛くなければ (if it's not spicy)
13. Noun negative: でなければ (if you're not)

### Pattern Implemented: ようになる (to reach the point of, to come to)

**JLPT Level**: N4
**Category**: Construction
**Priority**: 1

**Pattern**: Expression combining the auxiliary verb ようだ with なる. Expresses that a particular action has reached the point of being completed or able to be completed. A natural change or development over time, different from ようにする which emphasizes conscious effort.

**Structures tested**: 5 tests covering all structure variants
1. Verb[できる] (potential) + ように + なる: 書けるようになります (will reach the point where you can write)
2. Verb[できる] + ように + なる (conjugated): 走れるようになりたい (want to reach the point where I can run)
3. 出来る + ように + なる: 出来るようになる (reach the point where one can do)
4. Verb[ない] + ように + なる: 使えないようになる (will reach the point where you can't use)
5. Verb[ない] + ように + なります (polite): できないようになります (will reach the point where you can't)

**Implementation details**:
- Matcher: grammar-lib/src/matchers/n4.rs (youninaru function, lines 2389-2444)
- Tests: grammar-lib/src/tests/n4_patterns.rs (youninaru_tests module, lines 9797-9855)
- Pattern: grammar-lib/src/patterns.rs (Youninaru, line 1573 - already existed)

**Tokenization pattern**:
```
Affirmative form (potential verb):
Verb (動詞/自立, 基本形, potential form like 書ける/走れる/出来る)
+ よう (名詞/非自立/助動詞語幹)
+ に (助詞/格助詞/一般)
+ なる (動詞/自立, base="なる")

Negative form:
Verb (動詞/自立, 未然形)
+ ない (助動詞, base="ない")
+ よう (名詞/非自立/助動詞語幹)
+ に (助詞/格助詞/一般)
+ なる (動詞/自立, base="なる")
```

**Key implementation points**:
1. VerbMatcher accepts any verb (potential, dictionary, or 未然形)
2. Optional NaiMatcher handles the ない auxiliary for negative forms
3. YouMatcher ensures よう is a dependent noun (非自立) with auxiliary verb stem (助動詞語幹)
4. NiParticleMatcher matches に as case particle (格助詞)
5. Uses TokenMatcher::specific_verb("なる") to match なる and all conjugations
6. Pattern range includes full construction: Verb(+ない) + よう + に + なる
