### Technical Notes

**Honorific Language (敬語) System**:
Japanese has three levels of honorific language:
1. **Respectful language (尊敬語)**: Honors the actions of others
   - なさる (for する), いらっしゃる (for いる/行く/来る)
2. **Humble language (謙譲語)**: Lowers speaker's actions
   - いたす (for する), 申す (for 言う)
3. **Polite language (丁寧語)**: Polite speech register
   - です/ます endings

**五段・ラ行特殊 Verbs**:
This special conjugation class includes honorific verbs:
- なさる (to do - honorific)
- くださる (to give - honorific)
- いらっしゃる (to be/go/come - honorific)
- おっしゃる (to say - honorific)

All have the special い-form polite conjugation instead of り-form.

**Comparison: なさる vs なさい**:
- なさる: Full verb, can be conjugated in all forms
- なさい: Imperative form only (command)
- Both use base_form="なさる" but different conjugation forms
- なさい specifically uses features[5]="命令ｉ" (imperative i-form)
- なさる uses various forms: 基本形, 連用形, 未然形, etc.

### Technical Notes

**Conditional Forms in Japanese**:
The pattern uses the conditional (仮定形) of the negative auxiliary ない:
- Full form: ない → なければ (if not)
- Contracted: ない → なきゃ (casual "if not")
- Both mean the same but differ in formality

**Double Negative Logic**:
The construction is a double negative that creates obligation:
- Literal: "If not do, cannot become" = "must do"
- しなければならない = "If (I) don't do, it won't become/work" = "I must do"

**いけない vs ならない**:
Both mean "won't do/won't work" but differ in usage:
- いけない: More common in speech, casual/neutral ("won't go")
- ならない: More formal, literary, or written contexts ("won't become")
- Both create the same grammatical function (obligation)

**Verb Conjugation Differences**:
- いける (一段 verb): いけ can be 未然形 or 連用形
- なる (五段 verb): なら (未然形) vs なり (連用形)
- The conjugation form changes based on what follows:
  - 未然形 + ない (negative auxiliary)
  - 連用形 + ます (polite auxiliary)

**Pattern Extension for Polite Forms**:
The pattern matcher automatically extends patterns when it detects polite auxiliaries:
- Base pattern: なければ + なら + ない
- Extended: なければ + なり + ます → なければなりません
- This is why making ない optional was crucial for detection

**Listing Particles in Japanese**:
This pattern is part of the listing particle family:
- とか: Non-exhaustive listing (verbs, adjectives, nouns) - casual
