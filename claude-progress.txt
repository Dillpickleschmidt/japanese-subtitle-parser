  - standard[3]: Noun + ではなくて + Phrase
  - Note: ではなくて can also be じゃなくて or でなくて
- **Tokenization**:
  - Two main patterns:
    1. Verb + なく(助動詞) + て: Verb[未然形] + なく (base='ない', pos=助動詞) + て (particle)

  - Matcher is simple and covers all use cases elegantly
- **Meaning**: Negative て-form, "because not", "not...and", "without being"
- **Pattern priority**: 1 (basic N4 construction)
- **Pattern ranges**:
  - なくて (chars 6-9) - verb negative: 来れなくて
  - なくて (chars 6-9, 22-25) - adjective negative (two instances in one sentence)
  - なくて (chars 10-13) - part of ではなくて
  - なくて (chars 4-7) - part of noun + ではなくて
  - なくて (chars 7-10) - part of じゃなくて
- **Test coverage**: 7 tests covering all structure variants
  1. Verb negative て-form (来れなくて)
  2. い-Adjective negative て-form with multiple instances (寒くはなくて, 着なくて)
  3. な-Adjective + ではなくて (便利ではなくて)
  4. Noun + ではなくて (虫歯ではなくて)
  5. Noun + じゃなくて casual variant (仕事じゃなくて)
  6. Verb potential negative (寝れなくて)
  7. Noun が + なくて (仕事がなくて)

- **Meaning**: "but", "however", "nevertheless" - formal conjunction
- **Pattern priority**: 2 (N4 construction)

  - だが (chars 12-14) - sentence-start conjunction form
  - ですが (chars 8-11) - polite split form
- **Test coverage**: 3 tests covering both structures and tokenization patterns
  - Mid-sentence だが (split: だ + が)
  - Sentence-start だが (single conjunction token)
  - Polite ですが (split: です + が)

### Implementation Notes
- **Dual tokenization**: Pattern handles two distinct tokenization cases
  1. **Sentence-start/after punctuation**: だが as single conjunction token (接続詞)
  2. **Mid-sentence**: Split into だ/です (auxiliary) + が (conjunction particle)
- **Elegant solution**: Using Optional matcher for が handles both cases:
  - When だが is conjunction, が doesn't match (correct - no second token)
  - When だ/です is auxiliary, が matches (correct - completes the pattern)
- **Pattern overlap**: The split form (だ/です + が) also matches the existing "が" N5 pattern (intentional - both show)
