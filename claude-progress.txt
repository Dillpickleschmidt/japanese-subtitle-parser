  - test_aruiwa_phrase_kamoshirenai (月曜日あるいは - あるいは at beginning)
- **Structures**:
  - (Optional か) + あるいは
  - Works after verbs, adjectives, and nouns
  - Can appear at the beginning of sentences/phrases
- **Tokenization insights**:
  - あるいは = 接続詞 (conjunction)
  - か = 助詞/副助詞／並立助詞／終助詞 (when present)
  - Pattern is simple: Optional(か) + あるいは
- **Implementation**: 2-token matcher with Optional
  - KaParticleMatcher: Matches か as 助詞/副助詞／並立助詞／終助詞
  - AruiwaMatcher: Matches あるいは as 接続詞
  - Uses TokenMatcher::Optional for the か particle
- **Meaning**: "or / alternatively / possibly" - presents alternatives or possibilities
- **Usage**: Common N3 conjunction for formal alternatives (more formal than それとも)
- **Pattern priority**: 3 (construction pattern - N3 level)
- **Pattern ranges**: Includes optional か + あるいは
  - With か: かあるいは (e.g., chars 6-11, 10-15, 2-7, 3-8)
  - Without か: あるいは (e.g., chars 2-6, 3-7)

### Technical Details
- **Pattern priority**: 3 (construction pattern - N3 level in patterns.rs)
- **Test coverage**: All major structure variants from grammar_points_data.json

- **Implementation approach**: Test-first workflow (print_debug → analyze tokenization → implement → finalize)
- **Key insight**: あるいは is always a conjunction (接続詞), preceded optionally by か particle
