### Key Learnings

1. **Pattern Overlap**: Multiple patterns can detect the same structure
   - Use priority to determine which pattern is selected
   - Lower priority patterns can still provide value (better ranges)

2. **Variable Token Matching**: Use Optional matchers for flexible sequences
   - `Optional(matcher)` handles cases where token may or may not be present
   - Works better than Wildcard for small variations

3. **な-Adjective Detection**: Requires special handling
   - Tokenizes as TWO tokens: stem (名詞/形容動詞語幹) + な (助動詞)
   - Must include both tokens in pattern range for proper detection

4. **Matcher Reusability**: Created general-purpose `PreTameMatcherAny`
   - Matches multiple POS types with OR logic
   - Can be reused in Optional contexts
